    Movement¶

    This page covers how the pawns move: gaits and rotation modes (both pawns), the Mover movement modes and transitions, and the slide. The animation side is in Animation pipeline.

    Input state¶

    Both pawns keep an input state (S_PlayerInputState): WantsToSprint (hold Shift), WantsToWalk (toggle Ctrl), WantsToStrafe (toggle middle mouse), WantsToAim (hold Right Button), WantsToCrouch (toggle C). Movement, animation and camera are derived from it. Each of these five can be switched between hold and toggle per pawn (Toggle Crouch, Toggle Walk, Toggle Sprint, Toggle Aim, Toggle Strafe).

    Gait¶

    Gait When (Mover pawn)
    Sprint Sprint held, not aiming, and (while strafing) the input is within Sprint Max Angle From Facing of the facing direction.
    Walk Walk toggled on, or a small stick deflection (DDCvar.AnalogInputStyle 1: below 0.7).
    Run Otherwise.

    In cover the gait is Walk (unless crouched), and during a cover run it is Sprint. The CMC pawn decides the same way (GetDesiredGait), with Movement Stick Mode and Analog Walk/Run Threshold (0.7) for the stick.

    Sprint Max Angle From Facing (on the pawn, GASPALS > Movement > Sprint): the Mover pawn has one angle per DDCvar.StrafeStyle (60 / 95.7 / 95.7 degrees), the CMC pawn one value (50). Raise it to let the character sprint sideways while strafing.

    Rotation mode¶

    Mode When The character faces
    OrientToMovement Default in third person Where it moves
    Strafe Strafe toggled on, in first person, while auto-strafing, or near a targeted actor The camera direction (the target when locked on)
    Aim Aim held The aim direction

    The camera uses the same mode to pick its Free, Strafe or Aim rig.

    Auto-strafe (GASPALS > Strafe on both pawns): with Auto Strafe Enabled, the third-person character strafes while the player looks around and orients to movement again Auto Strafe Delay (1 s) after the look input stops. It only matters while strafe is toggled off; the CMC pawn starts strafing. On the CMC pawn the state is sent to the server with the rest of the input state, so other players see the same facing.

    Target lock: actors that call AddTarget / RemoveTarget on the pawn (the TargetDummy does on overlap) can be locked on; the nearest one is marked with a red cone and the character keeps facing it, out of cover. Both pawns support it; the CMC pawn turns toward the target at Target Lock Interp Speed (10).

    Speeds¶

    Set on the Walking mode instance of each pawn's CharacterMover component (category Blueprint Overrides (Change These)):

    Setting Default
    Walk Speed / Walk Acceleration 165 / 500
    Run Speed / Run Acceleration 375 / 800
    Sprint Speed / Sprint Acceleration 585 / 300
    Crouch Speed 165
    Walk/Run Turn Strength / Sprint Turn Strength 8 / 4
    Gait Change Deceleration / Stopping Deceleration 300 / 1000
    Walk/Run Facing Time / Sprint Facing Time / Idle Facing Time 0.4 / 0.8 / 0.2 (the sample pawns use 0.1 for walk/run and idle)

    The Cover mode (a child of Walking) moves at 150 (walk) and 250 (run and sprint).

    Right after landing the Walking mode brakes with Just Landed Deceleration (20000) for Just Landed Duration (0.2 s), so the character doesn't slide. The Falling mode turns at most Falling Rotation Rate (300 degrees per second).

    Set on the pawn (class defaults). Each is a vector: forward, strafe, backward speed, blended by direction with Curve_StrafeSpeedMap while strafing.

    Setting Forward, strafe, backward
    Walk Speeds 200, 180, 150
    Run Speeds 500, 350, 300
    Sprint Speeds 700, 700, 700
    Crouch Speeds 225, 200, 180

    UpdateMovement_PreCMC writes the resulting max speed, acceleration, braking and friction into the Character Movement Component every frame, before it moves, so change them on the pawn (GASPALS > Movement > CMC), not on the component:

    Setting Default
    Gait Max Acceleration 800, 800, 300 (walk, run, sprint at top speed)
    Sprint Acceleration Speed Range 300 to 700 (sprint acceleration eases from the run value to the sprint value over this speed range)
    Gait Ground Friction 5, 5, 3
    Sprint Ground Friction Speed Range 0 to 500
    Braking Deceleration 500 with movement input, 2000 when stopping (also in cover)
    Stopping Braking Friction 3
    Falling Rotation Rate 200 degrees per second

    Mover movement modes¶

    Registered on CharacterMover > Movement Modes of the Mover pawn:

    Name Class Use
    Walking BP_MovementMode_Walking (Smooth Walking) Ground movement with gait speeds, turning and facing.
    Falling BP_MovementMode_Falling Air: air control 0.5.
    Flying B_MovementMode_Flying Traversal moves, debug flying (max speed 1000).
    Sliding BP_MovementMode_Slide Slide.
    Cover BP_MovementMode_Cover Along cover (see Cover).
    Traversing Flying (native) Registered but not used.
    Ragdoll BP_MovementMode_Ragdoll Physics ragdoll (X); see Ragdoll and interactions.

    Shared settings: legacy movement settings (max step height 30, perch radius 20) and stance settings (crouched half height 60). Sync Inputs For Sim Proxy is on, so remote characters receive the inputs for animation.

    The pawn's Movement Mode Map translates mode names into the animation's movement modes (E_MovementMode): Cover counts as on ground, Sliding as sliding, and so on.

    Transitions¶

    Transition Where Condition
    BP_MovementTransition_Cover Global Walking to Cover and back, from the cover input.
    BP_MovementTransition_ToSlide Walking and Cover modes Speed over Slide Enter Speed (380), crouching, not in cover, cooldown over.
    BP_MovementTransition_FromSlide Sliding mode Not crouching, or speed at or below Slide Exit Speed (200).
    BP_MovementTransition_SuggestedMode Global Applies a mode requested in the input (ragdoll enter and exit).

    Transitions are instanced per mode: each mode carries its own copy.

    Slide¶

    Sprint, then crouch: the Mover pawn slides. BP_MovementMode_Slide is a smooth walking mode whose speed and deceleration depend on the slope:

    Setting Default
    Initial Boost Time / Speed / Acceleration 0.2 s / 800 / 2000
    After Boost Acceleration 300
    Steep Slope Angle / Shallow Slope Angle 40 / 10 degrees
    Steep Slope Speed / Shallow Slope Speed / Flat Ground Speed 800 / 500 / 100
    Steep Slope Deceleration / Flat Ground Deceleration 2000 / 500
    Slide Cooldown 0.75 s
    Slide Enter Speed / Slide Exit Speed 380 / 200

    The slide starts when the speed is over Slide Enter Speed (380; running forward is about 375, so it needs a sprint), the character crouches, is not in cover, and the cooldown is over. It ends when the character stands up or slows to Slide Exit Speed (200). The transitions read both from the Slide mode.

    Slide Cooldown stops crouch-tapping from restarting the slide with a fresh boost: a new slide can start only 0.75 s after the last one started or ended. It is measured in Mover simulation time, so the server and the predicting client agree. It is set on the Slide mode instance of each pawn.

    The CMC pawn has no slide.

    Debug¶

    • p.VisualizeMovement 1 shows the movement state.
    • On the Mover pawn, Z (keyboard only) toggles a debug flying mode (debug tools).
