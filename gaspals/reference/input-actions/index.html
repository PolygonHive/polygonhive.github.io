    Input actions¶

    Input actions are in /GASPALS/Input, mapped in /GASPALS/Input/Mappings/IMC_Sandbox (the context the pawns add). "Mover" is SandboxCharacter_Mover, "CMC" is SandboxCharacter_CMC.

    Locomotion¶

    Action Keys Handled by Mover CMC
    IA_Move W A S D, left stick Pawn Read in ProduceInput (camera relative) Add Movement Input (camera relative)
    IA_Move_WorldSpace Arrow keys Pawn Not used Add Movement Input in world X/Y
    IA_Look_Mouse Mouse Pawn Yaw and pitch Yaw and pitch
    IA_Look_Gamepad Right stick Pawn Yaw and pitch (scaled by frame time) The same
    IA_Look_Gamepad_FixedCamera Right stick Pawn, AC_CameraSystem Aim direction in fixed cameras The same
    IA_Sprint Shift, ++lb++ Pawn Hold; stands up from crouch Hold
    IA_Walk Ctrl, ++rb++ Pawn Toggle (not while sprinting) Toggle
    IA_Crouch C, B Pawn Toggle (on the ground or sliding) Toggle (not falling)
    IA_Strafe Middle Button, ++l3++ Pawn Toggle Toggle (starts on)
    IA_Aim Right Button, < Pawn Hold Hold
    IA_Jump Space, A Pawn Cover vault, traversal, else jump (crouched: stand up; sliding: stand up). Held: retries traversal. In ragdoll on the ground: get up. Cover vault, traversal, else jump

    Systems¶

    Action Keys Handled by Does
    IA_Cover Q Pawn Started: RequestStickyCover; released: ReleaseStickyCover.
    IA_Equipment T AC_EquipmentSystem Hold: equipment menu.
    IA_Overlay_Pose V AC_OverlaySystem Hold: overlay pose menu.
    IA_Overlay_Body B AC_OverlaySystem Hold: overlay body menu.
    IA_Select_Next / IA_Select_Previous Wheel up / down, D-pad up / down Equipment and overlay components Move the highlight of an open menu.
    IA_Camera_Perspective 1 AC_CameraSystem Next allowed perspective (blocked while camera control is off; does nothing with one allowed perspective).
    IA_Camera_Style 2 AC_CameraSystem Next style.
    IA_Camera_SwitchShoulder Alt, ++r3++ AC_CameraSystem Toggle the shoulder.
    IA_Interact E, Y AC_SmartObjectAnimation; Mover pawn, AC_DebugTools Use a smart object (bench). Mover pawn: shove, or with aim held spawn/rotate a character (debug tools).

    Ragdoll and interactions¶

    Action Keys Handled by Does
    IA_Ragdoll X, X (gamepad) AC_RagdollSystem (CMC pawn), Mover pawn CMC: toggle ragdoll. Mover: ragdoll (get up with jump).
    IA_TriggerRagdoll none Not mapped in IMC_Sandbox (the Mover pawn uses IA_Ragdoll).
    IA_Takedown Left Button Mover pawn, AC_DebugTools Takedown; with aim held, demo shoot (debug tools).

    Demo¶

    Action Keys Handled by Does
    IA_NextPawn N PC_Sandbox Next pawn class (server RPC to the game mode).
    IA_NextVisualOverride M PC_Sandbox Next character.
    IA_TeleportToTarget J PC_Sandbox; AC_DebugTools on the Mover pawn Teleport to the point under the view (up to 100 m).

    The Mover pawn also toggles a debug flying mode with Z (keyboard only, through its AC_DebugTools). This is a raw key node in the Mover pawn's Event Graph, not an input action.

    Unused¶

    Asset Note
    IA_TwinStick_AimDirection Read by the Mover pawn's twin-stick mode but not mapped.
