    Movement modes reference¶

    The Mover movement modes and transitions used by the Mover pawn.

    How to read these tables

    Settings are the values you tune: select the component in your pawn Blueprint (or open the asset) and look in the Details panel under the category shown. Runtime state is written by the system while it runs; read it, do not set it. Functions marked pure have no execution pins. The descriptions are the same as the Details panel tooltips. Default is the class default; where a sample pawn sets a different value on its component, the description says so ().

    Movement > Landing¶

    Variable Type Default Description
    Just Landed Deceleration
    JustLandedDeceleration    		 Float 20000 Stopping deceleration (cm/s2) used right after landing, for JustLandedDuration, so the character doesn't slide on landing. Also used by the Cover mode (a child of this mode). Default 20000.
    Just Landed Duration
    JustLandedDuration    		 Float 0.2 How long (s) after landing JustLandedDeceleration applies. Default 0.2.

    Movement > Slide¶

    Variable Type Default Description
    Slide Cooldown
    SlideCooldown    		 Float 0.75 Seconds after a slide starts or ends before another slide can start. Stops slide spam (crouch, stand, crouch at sprint speed re-applying the initial boost). 0 turns the cooldown off.
    Slide Enter Speed
    SlideEnterSpeed    		 Float 380 Ground speed (cm/s) above which crouching starts a slide (BP_MovementTransition_ToSlide). The run speed is 375, so the default 380 needs a sprint. Default 380.
    Slide Exit Speed
    SlideExitSpeed    		 Float 200 The slide ends (BP_MovementTransition_FromSlide) at or below this ground speed (cm/s), or when the character stops crouching. Default 200.
