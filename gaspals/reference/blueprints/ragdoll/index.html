    Ragdoll reference¶

    The ragdoll component used by the Character (CMC) pawn, and the Mover ragdoll mode.

    How to read these tables

    Settings are the values you tune: select the component in your pawn Blueprint (or open the asset) and look in the Details panel under the category shown. Runtime state is written by the system while it runs; read it, do not set it. Functions marked pure have no execution pins. The descriptions are the same as the Details panel tooltips. Default is the class default; where a sample pawn sets a different value on its component, the description says so ().

    Functions¶

    Function Inputs Outputs Description
    GetGetUpAnimation (pure) RagdollFaceUp (Boolean) ReturnValue (AnimMontage ref) Returns the get-up montage for the ragdoll side (RagdollFaceUp) and the selected equipment. Called when the ragdoll ends on the ground.
    InitializeSystem ParentPawn (Pawn ref), ParentMesh (SkeletalMeshComponent ref), ParentCapsule (CapsuleComponent ref)   Stores the owning pawn, mesh and capsule and finds the Character Movement Component. Called once by the pawn.
    IsRagdolling (pure)   bIsRagdolling (Boolean) True while the character is ragdolling.
    SetActorLocationAndRotation(UpdateTarget) NewLocation (Vector), NewRotation (Rotator), bSweep (Boolean), bTeleport (Boolean) SweepHitResult (HitResult), ReturnValue (Boolean) Moves the owning pawn to the location and stores the rotation as RagdollTargetRotation.
    SetActorLocationDuringRagdoll     Moves the capsule to follow the pelvis while ragdolling, resting it on the ground when one is found below, and updates the face-up and on-ground flags.
    UpdateRagdoll     Per-tick ragdoll update: stores the pelvis velocity, scales the angular motors with it, disables gravity far below the start and moves the actor to the pelvis.

    Events¶

    • OnRagdollStarted (event dispatcher): Dispatcher called when StartRagdoll runs.
    • OnRagdollEnded (event dispatcher): Dispatcher called when StopRagdoll runs.
    • Multicast_StartRagdoll: Multicast RPC, reliable.
    • Server_StopRagdoll: Server RPC, reliable.
    • Server_StartRagdoll: Server RPC, reliable.
    • Multicast_StopRagdoll: Multicast RPC, reliable.
