    Ragdoll reference¶

    The ragdoll core component and its two movement adapters, on both pawns. Add AC_RagdollSystem_Mover to a Mover pawn or AC_RagdollSystem_CMC to a Character pawn: both inherit every setting of AC_RagdollSystem_Base.

    How to read these tables

    Settings are the values you tune: select the component in your pawn Blueprint (or open the asset) and look in the Details panel under the category shown. Runtime state is written by the system while it runs; read it, do not set it. Functions marked pure have no execution pins. The descriptions are the same as the Details panel tooltips. Default is the class default; where a sample pawn sets a different value on its component, the description says so ().

    AC_RagdollSystem_Base¶

    /GASPALS/Systems/RagdollSystem/AC_RagdollSystem_Base · parent ActorComponent

    Settings¶

    Ragdoll > Entry¶

    Variable Type Default Description
    Left Leg Bones
    LeftLegBones    		 Array of Name thigh_l, calf_l, foot_l Left leg bodies that collide with RightLegBones during ragdoll, so the legs do not pass through each other. Set per skeleton.
    Right Leg Bones
    RightLegBones    		 Array of Name thigh_r, calf_r, foot_r Right leg bodies that collide with LeftLegBones during ragdoll. Set per skeleton.
    Default Ragdoll Montage Blend Out
    DefaultRagdollMontageBlendOut    		 MontageBlendSettings Montage blend-out used when the ragdoll stops the active montages: the ragdoll input (HandleRagdollInput), an obstacle hit (TraceForObstacles), and on the Mover pawn the Ragdoll mode entry on machines that have not applied the ragdoll physics yet (ApplyModeEnterPhysics).

    Ragdoll > General¶

    Variable Type Default Description
    Enable Ragdoll
    bEnableRagdoll    		 Boolean true Turns the ragdoll system on or off (read at start, default only). Off: StartRagdoll and the ragdoll input do nothing.

    Ragdoll > Get Up¶

    Variable Type Default Description
    Auto Get Up
    bAutoGetUp    		 Boolean true Characters without a player get up by themselves once the body has rested for AutoGetUpDelay (server only). Off: they stay down until something calls RequestGetUp.
    Auto Get Up Delay
    AutoGetUpDelay    		 Float 3 Seconds the body must rest before an automatic get-up. Default 3.
    Auto Get Up Max Speed
    AutoGetUpMaxSpeed    		 Float 30 Speed in cm/s of the spine_05 body (RagdollSpeed) under which the body counts as resting. Default 30.

    Ragdoll > Motion¶

    Variable Type Default Description
    Ragdoll Gravity Multiplier
    RagdollGravityMultiplier    		 Float 1 Gravity multiplier on every ragdoll body (UpdateGravity, needs the PhysicsControl component); gravity is turned off once the body falls faster than 2500 cm/s.
    Ragdoll Roll Torque
    RagdollRollTorque    		 Float 100000 Torque (degrees, acceleration change) applied to spine_05 per unit of roll force (move input while ragdolling, plus the automatic roll on slopes). 0 turns rolling off. Default 100000.
    Ragdoll Auto Roll Slope Min
    RagdollAutoRollSlopeMin    		 Float 20 Floor angle (degrees) where the automatic roll down slopes starts. Default 20.
    Ragdoll Auto Roll Slope Max
    RagdollAutoRollSlopeMax    		 Float 30 Floor angle (degrees) where the automatic roll down slopes reaches full strength. Default 30.

    Ragdoll > Obstacles¶

    Variable Type Default Description
    Ragdoll on Obstacle Hit
    bRagdollOnObstacleHit    		 Boolean true Ragdoll when an obstacle hits the body (TraceForObstacles, every tick on the locally controlled owner while not ragdolling). Off: obstacles only push the capsule. Default on.
    Ragdoll Obstacle Object Types
    RagdollObstacleObjectTypes    		 Array of EObjectTypeQuery ObjectTypeQuery7 Object types that knock the character over (TraceForObstacles sweeps from neck_01 to between the feet). Default Obstacle: the moving obstacles of RagdollLevel (ObstaclePreset profile).
    Ragdoll Obstacle Trace Radius
    RagdollObstacleTraceRadius    		 Float 15 Radius in cm of the obstacle sweep along the body. Default 15.

    Ragdoll > Physics¶

    Variable Type Default Description
    Physics Control Kinematic Tick Interval
    PhysicsControlKinematicTickInterval    		 Float 0.25 Tick interval (seconds) of the pawn's Physics Control component while the Kinematic profile is applied. In that profile every control is off and the component only re-targets the kinematic bodies to their bones, which the skeletal mesh already does, so it can tick slowly. The other profiles (Ragdoll, PhysicalAnimation) always tick every frame. 0 = every frame. Default 0.25.

    Ragdoll > Replication¶

    Variable Type Default Description
    Remote Sync Stiffness
    RemoteSyncStiffness    		 Float 25 Spring strength pulling a remote copy of the ragdoll (a machine that does not drive it) toward the replicated capsule position, on the pelvis. Default 25.
    Remote Sync Damping
    RemoteSyncDamping    		 Float 10 Damping of the remote ragdoll pull (see RemoteSyncStiffness). Default 10.

    Ragdoll > Settle¶

    Variable Type Default Description
    Ragdoll Settle Speed
    RagdollSettleSpeed    		 Float 15 Spine speed (cm/s) below which the ragdoll counts as lying still.
    Ragdoll Settle Delay
    RagdollSettleDelay    		 Float 0.3 Seconds the ragdoll must stay below RagdollSettleSpeed before the physics control strengths fade out.
    Ragdoll Settle Blend Time
    RagdollSettleBlendTime    		 Float 0.5 Seconds to fade the physics control strengths to 0 once the ragdoll has settled (they come back 4x faster when the body moves again). Fading them out keeps the arms from chasing the animation pose, which would make the hands shake.
    Ragdoll Settle Wake Speed
    RagdollSettleWakeSpeed    		 Float 60 Once the ragdoll has settled (below Ragdoll Settle Speed for Ragdoll Settle Delay), only a spine speed above this (cm/s) wakes its physics controls again. Stops the limbs that drop as the controls fade from waking them again, which kept bodies twitching on the ground and delayed the auto get-up. Never below Ragdoll Settle Speed.
    Runtime state (32 variables)
    Variable Type Default Description
    Pending Ragdoll Impulse
    PendingRagdollImpulse    		 Vector (0, 0, 0) Impulse waiting for the body to switch to the Ragdoll profile before it is applied (TryApplyPendingImpulse, 1 s expiry).
    Pending Ragdoll Impulse Bone
    PendingRagdollImpulseBone    		 Name Bone that receives PendingRagdollImpulse.
    Pending Ragdoll Impulse Time
    PendingRagdollImpulseTime    		 Float 0 Game time when PendingRagdollImpulse was received (expires after 1 s).
    Ragdoll Spine Velocity
    RagdollSpineVelocity    		 Vector (0, 0, 0) Linear velocity of the spine_05 body while ragdolling (UpdateVelocities); feeds the impact prediction.
    Ragdoll Speed
    RagdollSpeed    		 Float 0 Speed of the spine_05 body while ragdolling: the settle and the automatic get-up read it.
    Ragdoll Time to Impact
    RagdollTimeToImpact    		 Float 0 Time until the predicted impact of the falling body (projectile path from the spine velocity, UpdateImpactDirection).
    Ragdoll Impact Direction
    RagdollImpactDirection    		 Vector2D (0, 0) Direction of the predicted impact relative to the RagdollTrace socket, as yaw (X) and pitch (Y) in degrees, read by the Anim Blueprint for bracing.
    Ragdoll COMLast Frame
    RagdollCOMLastFrame    		 Vector (0, 0, 0) Skeletal center of mass of the previous frame, for RagdollCOMVelocity.
    Ragdoll COMVelocity
    RagdollCOMVelocity    		 Vector (0, 0, 0) Velocity of the skeletal center of mass while ragdolling (UpdateVelocities). Above 150 cm/s horizontally the get-up uses the rolling variants (PlayRollingGetups); falling faster than 2500 cm/s turns the ragdoll gravity off (UpdateGravity).
    Ragdoll Roll Input
    RagdollRollInput    		 Vector (0, 0, 0) Roll input of the ragdoll: the owner's move input, or on other machines the replicated value (UpdateRollInput).
    Ragdoll Roll Force
    RagdollRollForce    		 Vector (0, 0, 0) Roll force of this frame: the roll input plus the automatic roll, clamped to 1 (UpdateRollBehavior).
    Ragdoll Auto Roll Force
    RagdollAutoRollForce    		 Vector (0, 0, 0) Automatic roll force down the slope, smoothed (UpdateRollBehavior).
    Parent Pawn
    ParentPawn    		 Pawn ref Owning pawn; set by InitializeSystem.
    Parent Mesh
    ParentMesh    		 SkeletalMeshComponent ref Skeletal mesh of the owning pawn that is simulated while ragdolling.
    Parent Capsule
    ParentCapsule    		 CapsuleComponent ref Capsule of the owning pawn; its collision is disabled during the ragdoll and its half height places the actor on the ground.
    Physics Control
    PhysicsControl    		 PhysicsControlComponent ref The owner's PhysicsControl component, found by InitializeSystem. Without one the ragdoll is limp: no Kinematic / Ragdoll profiles, curve strengths, settle or gravity multiplier.
    Owner Set Up
    bOwnerSetUp    		 Boolean false True once InitializeSystem has bound the owner events and created the physics controls, so a second call (the CMC pawn initializes its systems again after a visual override change) does not create them twice.
    Default Physics Profile
    DefaultPhysicsProfile    		 Name Kinematic Physics Control profile used outside ragdoll: Kinematic, or PhysicalAnimation when DDCVar.CharacterPhysics.DefaultProfile is 1 (UpdateDefaultPhysicsProfileFromCvar).
    Applied Physics Profile
    AppliedPhysicsProfile    		 Name The Physics Control profile currently invoked (Kinematic, PhysicalAnimation or Ragdoll), set by SetPhysicsProfile.
    Loaded Physics Control Asset
    LoadedPhysicsControlAsset    		 Object ref The PhysicsControl component's Physics Control Asset, kept loaded from InitializeSystem. The component only holds it through a soft pointer, so without this reference a packaged game unloads it at the first garbage collection and the ragdoll profiles stop applying.
    Default Capsule Profile
    DefaultCapsuleProfile    		 Name The capsule collision profile the owner had at InitializeSystem; the get-up restores it.
    Ragdoll Settle Alpha
    RagdollSettleAlpha    		 Float 0 How settled the ragdoll is, 0 (moving) to 1 (still): the physics control strengths are scaled by 1 - this.
    Ragdoll Settle Timer
    RagdollSettleTimer    		 Float 0 Seconds the ragdoll has stayed below RagdollSettleSpeed.
    Last Ragdoll Sound Time
    LastRagdollSoundTime    		 Float -1 Game time of the last ragdoll impact sound (OnRagdollHit plays at most one every 0.3 s).
    Is Ragdolling
    bIsRagdolling    		 Boolean false True while the character is ragdolling; UpdateRagdollSystem runs the ragdoll motion (UpdateRagdollMotion) every tick while set, and the obstacle trace otherwise.
    Ragdoll on Ground
    RagdollOnGround    		 Boolean false True when there is floor under the ragdoll, updated every tick by UpdateRagdollFloor (base: a line trace below the pelvis; Mover adapter: the Mover floor query; CMC adapter: also the server capsule trace). RequestGetUp only gets the character up while it is true.
    Ragdoll Face Up
    RagdollFaceUp    		 Boolean false True when the pelvis faces up (lying on the back); picks the back or front get-up montages.
    Auto Get Up Still Time
    AutoGetUpStillTime    		 Float 0 Seconds the ragdoll has rested, for the automatic get-up (UpdateAutoGetUp): counts up while RagdollSpeed is under AutoGetUpMaxSpeed and back down while the body moves faster. Reset to 0 when the get-up is requested, by PrepareGetUp, and while the automatic get-up does not apply (players, clients, bAutoGetUp off).
    Ragdoll Injury State
    RagdollInjuryState    		 E_RagdollInjuryState None Injury state of the current ragdoll (read by the Anim Blueprint through the ragdoll properties); reset on the get-up. Replicated. (replicated)
    Freeze Capsule Rotation
    bFreezeCapsuleRotation    		 Boolean false True for 0.25 s after the ragdoll starts, so the capsule keeps its rotation while the body starts to fall.
    Ragdoll Floor Normal
    RagdollFloorNormal    		 Vector (0, 0, 0) Normal of the floor under the ragdoll (UpdateRagdollFloor), for the automatic roll on slopes.
    Debug State
    DebugState    		 Integer 0 DDCVar.CharacterPhysics.DrawDebug, read every frame; draws the obstacle, impact and roll debug shapes when above 0.

    ApplyRagdollPhysics bStopMontages (Boolean), MontageBlendOut (MontageBlendSettings)   Starts the ragdoll physics on this machine: stops the active montages (optional), simulates the mesh and applies the Ragdoll physics profile.
    InvokeControlProfileIfValid PhysicsProfile (Name)   Invokes the Physics Control profile when the owner has a PhysicsControl component.
    OnDDCvarChanged CVarName (String)   Data-driven console variable changed: updates the default physics profile when it was DDCVar.CharacterPhysics.DefaultProfile.
    ResetParentSpaceControls     Get-up: sets the ParentSpace controls to zero strength and zero target velocity multipliers, so the get-up does not inherit the ragdoll velocities. Needs the PhysicsControl component.
    RestoreDefaultPhysicsProfile     Applies DefaultPhysicsProfile unless the character is ragdolling again.
    SetPhysicsProfile PhysicsProfile (Name)   Applies a physics profile: stores it in AppliedPhysicsProfile, invokes it on the PhysicsControl component when there is one, then sets the leg-to-leg collision and constraint profile (Kinematic: off, Free; Ragdoll: on, default). In the Kinematic profile the PhysicsControl component ticks every Physics Control Kinematic Tick Interval seconds; every frame otherwise.
    SimulateRagdollBodies   bHandled (Boolean) Starts simulating every mesh body for the ragdoll (SetSimulatePhysics), called by ApplyRagdollPhysics; adapters can override it. The CMC adapter starts its bodies in ActivateRagdoll instead (the bodies below the pelvis), because it moves the capsule onto the body every frame.
    StopActiveMontages bStopMontages (Boolean), MontageBlendOut (MontageBlendSettings)   Stops every active montage with the given blend-out when bStopMontages is set.
    UpdateDefaultPhysicsProfileFromCvar     Reads DDCVar.CharacterPhysics.DefaultProfile (0 Kinematic, 1 PhysicalAnimation) into DefaultPhysicsProfile and applies it unless the character is ragdolling.
    ApplyCurveStrengths     In the Ragdoll profile: scales the legs, arms, torso and head control strengths by the Ragdoll_Strength_* animation curves and the settle scale.
    GetRagdollStrengthScale (pure)   Scale (Float) Multiplier for the ragdoll physics control strengths: 1 - RagdollSettleAlpha.
    GetSettleSpeedThreshold (pure)   ReturnValue (Float) Speed under which the ragdoll counts as still for the settle timer: Ragdoll Settle Speed until it has settled, then Ragdoll Settle Wake Speed (hysteresis).
    UpdatePhysicsStrengthsFromCurves     Every frame, after the Anim Blueprint: updates the settle, then scales the ragdoll control strengths by the curves.
    UpdateSettle     Every frame: tracks how long the ragdoll has been still (RagdollSpeed under RagdollSettleSpeed) and moves RagdollSettleAlpha toward 1 (settled) or back to 0 (moving).
    BindOwnerEvents     Binds the mesh hit event (ragdoll impact sounds) and the data-driven console variable changes (default physics profile).
    InitializeSystem ParentPawn (Pawn ref), ParentMesh (SkeletalMeshComponent ref), ParentCapsule (CapsuleComponent ref) bInitialized (Boolean) Stores the owner references and checks them (ValidateSetup): with a missing pawn, mesh or capsule it returns false and the ragdoll stays off. Otherwise it finds the owner's PhysicsControl component, caches the capsule collision profile, runs SetupOwnerOnce (tick after the mesh, owner events, physics controls, default profile) and returns true. Call from the owner's initialization; adapters extend it (parent call first) to find their movement component.
    SetupOwnerOnce     First InitializeSystem call only: ticks after the mesh, binds the owner events, creates the physics controls and applies the default physics profile.
    SetupPhysicsControl     With a PhysicsControl component: creates its controls and body modifiers from its Physics Control Asset, keeps the asset loaded (LoadedPhysicsControlAsset) and makes it tick after this component.
    ValidateSetup   bValid (Boolean) Checks the owner references set by InitializeSystem. Missing pawn, mesh or capsule: an on-screen and log warning, the ragdoll stays off (returns false). No PhysicsControl component on the owner: a warning, the ragdoll works as a plain limp ragdoll without physical animation, settling or roll.
    OnRagdollHit HitComponent (PrimitiveComponent ref), OtherActor (Actor ref), OtherComp (PrimitiveComponent ref), NormalImpulse (Vector), Hit (HitResult)   Mesh hit while ragdolling: plays the ragdoll impact sound, louder with the bone speed (above 50 cm/s and a 100 impulse, at most every 0.3 s).
    PlayRagdollSound Volume (Float)   Plays the Foley.Event.Ragdoll event on the owner's AC_FoleyEvents component, when it has one.
    GetPropertiesForRagdoll (pure)   Properties (S_RagdollProperties) Ragdoll values for the Anim Blueprint (S_RagdollProperties): speed, time to impact, roll amount, impact direction, injury state.
    IsRagdolling (pure)   bIsRagdolling (Boolean) True while the character is ragdolling.
    IsRemoteCopy   bRemote (Boolean) True on a machine that does not drive this ragdoll, so its body is pulled toward the replicated capsule (SyncRemoteBody). Base: the locally controlled machine drives it, or the server for a character without a player. The CMC adapter overrides it: only the server drives.
    ApplyRollTorque     Turns the roll force into a torque on spine_05 (RagdollRollTorque) while the body simulates.
    SyncRemoteBody     Machines that do not drive this ragdoll (IsRemoteCopy): pulls the pelvis toward the replicated capsule position (RemoteSyncStiffness, RemoteSyncDamping).
    UpdateGravity     Applies RagdollGravityMultiplier to every body, or no gravity once the body falls faster than 2500 cm/s (needs the PhysicsControl component).
    UpdateImpactDirection     Predicts where the falling body lands (projectile path from the spine velocity) and stores the time to impact and the impact direction for the Anim Blueprint.
    UpdateRagdollFloor   bOnGround (Boolean) Finds the floor under the ragdoll and stores RagdollOnGround and RagdollFloorNormal. Base: a line trace below the pelvis; adapters can override it (the Mover adapter uses the Mover floor query).
    UpdateRagdollMotion     Per tick while ragdolling: velocities, floor, impact prediction, roll, gravity, remote body pull, pending impulse and the automatic get-up.
    UpdateRagdollSystem DeltaTime (Float)   Per tick: reads the debug console variable, updates the physics strengths, then either the ragdoll motion (ragdolling) or the obstacle trace.
    UpdateRollBehavior     Roll force of the ragdoll: the roll input plus an automatic roll down slopes steeper than RagdollAutoRollSlopeMin, then the torque on the spine.
    UpdateRollInput   RollInput (Vector) Returns the roll input of this frame. Base: the owner's last movement input on its machine, else the stored value; adapters override it.
    UpdateVelocities     Updates the center of mass velocity and the spine_05 velocity and speed of the ragdoll.
