    Overlay reference¶

    The overlay component and the overlay Anim Blueprints (pose, body, first person, layer blending).

    How to read these tables

    Settings are the values you tune: select the component in your pawn Blueprint (or open the asset) and look in the Details panel under the category shown. Runtime state is written by the system while it runs; read it, do not set it. Functions marked pure have no execution pins. The descriptions are the same as the Details panel tooltips. Default is the class default; where a sample pawn sets a different value on its component, the description says so ().

    AC_OverlaySystem¶

    /GASPALS/Systems/OverlaySystem/AC_OverlaySystem · parent ActorComponent · implements BPI_OverlaySystem_C

    Settings¶

    Overlay > General¶

    Variable Type Default Description
    Enable Overlay
    bEnableOverlay    		 Boolean true Turns the overlay system on or off (read at start, default only). Off: default overlay pose and body, overlay input ignored.

    Overlay > Selection¶

    Variable Type Default Description
    Overlay Body
    OverlayBody    		 Enum_OverlayBody Default Selected overlay body (Default, Masculine, Feminine); replicated, OnRep relinks the body anim layer. (replicated (RepNotify))
    Overlay Pose
    OverlayPose    		 Enum_OverlayPose Default Selected overlay pose (held item or stance, e.g. Default, Injured, HandsTied); replicated, OnRep relinks the pose anim layer. (replicated (RepNotify))
    Overlay Pose Layers
    OverlayPoseLayers    		 Map of Enum_OverlayPose Enum_OverlayPose::NewEnumerator0, ABP_Overlay_Default, Enum_OverlayPose::NewEnumerator17, ABP_Overlay_Injured, Enum_OverlayPose::NewEnumerator18, ABP_Overlay_HandsTied Anim layer class (ALI_OverlayPose) linked for each overlay pose: Default, Injured, HandsTied. To add a stance: add an Enum_OverlayPose entry, an ABP implementing ALI_OverlayPose, and a row here (the menu lists new enum entries automatically). A pose with no row keeps the current layer and prints a warning. Item poses come from the equipment data instead.
    Overlay Body Layers
    OverlayBodyLayers    		 Map of Enum_OverlayBody Enum_OverlayBody::NewEnumerator17, ABP_OverlayBody_Default, Enum_OverlayBody::NewEnumerator12, ABP_OverlayBody_Masculine, Enum_OverlayBody::NewEnumerator13, ABP_OverlayBody_Feminine Anim layer class (ALI_OverlayBody) linked for each overlay body: Default, Masculine, Feminine. To add a body style: add an Enum_OverlayBody entry, an ABP implementing ALI_OverlayBody, and a row here. A body with no row keeps the current layer and prints a warning.

    Overlay > UI¶

    Variable Type Default Description
    Overlay Pose Menu Widget Class
    OverlayPoseMenuWidgetClass    		 UserWidget class W_Switcher_Pose Widget shown while the overlay pose menu key is held. Default W_Switcher_Pose. A replacement only needs to display HighlightedOverlayPose; scrolling and selecting are handled by this component.
    Overlay Body Menu Widget Class
    OverlayBodyMenuWidgetClass    		 UserWidget class W_Switcher_Body Widget shown while the overlay body menu key is held. Default W_Switcher_Body. A replacement only needs to display HighlightedOverlayBody; scrolling and selecting are handled by this component.
    Menu Time Dilation
    MenuTimeDilation    		 Float 0.35 World time dilation while the menu is open (1 = no slow motion). Global: on a listen server the host's menu slows every player. Default 0.35.
    Runtime state (2 variables)
    Variable Type Default Description
    Highlighted Overlay Pose
    HighlightedOverlayPose    		 Enum_OverlayPose Default Pose highlighted in the open overlay pose menu: starts on OverlayPose, moved by scrolling, selected on release. The menu widget displays it.
    Highlighted Overlay Body
    HighlightedOverlayBody    		 Enum_OverlayBody Default Body style highlighted in the open overlay body menu: starts on OverlayBody, moved by scrolling, selected on release. The menu widget displays it.

    Functions¶

    Function Inputs Outputs Description
    RefreshOverlayPose   bHandled (Boolean)  
    UpdateOverlayBody     Links the anim layer class OverlayBodyLayers gives for the selected OverlayBody onto the parent mesh. No row for the body: the layer is unchanged and a warning is printed. Does nothing until InitializeSystem has set ParentMesh.
    UpdateOverlayPose     Links the anim layer class OverlayPoseLayers gives for the selected OverlayPose onto the parent mesh (replacing the previous pose layer). No row for the pose: the layer is unchanged and a warning is printed. Does nothing until InitializeSystem has set ParentMesh.
    ApplyOverlaySwitch     When bEnableOverlay is off: default pose and body before the layers are linked.
    InitializeSystem ParentMesh (SkeletalMeshComponent ref)   Stores the parent mesh and links the initial overlay body and pose anim layers. Called once by the owner on setup.
    CloseOverlayMenus     Closes the overlay pose and body menus without selecting anything: removes the switcher widgets and restores global time dilation to 1. Called from EndPlay, so a pawn destroyed with a menu open does not leave the game slowed down.
    ConfirmOverlayBodyMenu     Closes the overlay body style menu and selects HighlightedOverlayBody.
    ConfirmOverlayPoseMenu     Closes the overlay pose menu and selects HighlightedOverlayPose.
    CycleHighlightedOverlayBody bNext (Boolean)   Moves HighlightedOverlayBody to the next (bNext) or previous value, wrapping around.
    CycleHighlightedOverlayPose bNext (Boolean)   Moves HighlightedOverlayPose to the next (bNext) or previous value, wrapping around.
    OpenOverlayBodyMenu     Opens the overlay body style menu for the owning player: MenuTimeDilation, highlight on the current body style, OverlayBodyMenuWidgetClass added to the viewport.
    OpenOverlayPoseMenu     Opens the overlay pose menu for the owning player: MenuTimeDilation, highlight on the current pose, OverlayPoseMenuWidgetClass added to the viewport.

    Events¶

    • UpdateSelectedOverlayPose: Server RPC, reliable.
    • UpdateSelectedOverlayBody: Server RPC, reliable.

    ABP_OverlayPose_Base¶

    /GASPALS/Systems/OverlaySystem/OverlayPose/ABP_OverlayPose_Base · parent AnimInstance · implements ALI_OverlayPose_C

    Settings¶

    Overlay > Aim¶

    Variable Type Default Description
    Aim Sweep Interp Speed Local
    AimSweepInterpSpeed_Local    		 Float 0 Arm pitch (aim sweep) interpolation speed on the machine that controls the pawn. 0 (default) = no interpolation: the weapon pitch follows the view at once. Above 0 it trails the camera (stepping when turning slowly). Set on every overlay child too (class defaults are not inherited by existing children).
    Aim Sweep Interp Speed Remote
    AimSweepInterpSpeed_Remote    		 Float 10 Arm pitch (aim sweep) interpolation speed on other machines, where the pitch arrives in network steps.

    Overlay > General¶

    Variable Type Default Description
    Can Aim
    bCanAim    		 Boolean false Whether this overlay allows aiming; when false the aim poses are skipped by the pose state machine.
    Ready Hold Time Idle
    ReadyHoldTime_Idle    		 Float 3 Seconds the weapon stays raised (Ready) after aiming before it is lowered (Relaxed) while standing still. Set per overlay in the child's class defaults; a very large value keeps it raised. Default 3.
    Ready Hold Time Moving
    ReadyHoldTime_Moving    		 Float 2 Same while moving. Sprinting always lowers it at once. Default 2.
    Aim Min Time
    AimMinTime    		 Float 0.75 Minimum time (s) in the Aiming state before releasing aim returns to Ready, so a short tap still shows the aim pose. Default 0.75.
