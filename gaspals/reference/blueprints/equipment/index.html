    Equipment reference¶

    The equipment component, the equipment data asset class and the item actors.

    How to read these tables

    Settings are the values you tune: select the component in your pawn Blueprint (or open the asset) and look in the Details panel under the category shown. Runtime state is written by the system while it runs; read it, do not set it. Functions marked pure have no execution pins. The descriptions are the same as the Details panel tooltips. Default is the class default; where a sample pawn sets a different value on its component, the description says so ().

    AC_EquipmentSystem¶

    /GASPALS/Systems/EquipmentSystem/AC_EquipmentSystem · parent ActorComponent · implements BPI_EquipmentSystem_C

    Settings¶

    Equipment > General¶

    Variable Type Default Description
    Enable Equipment
    bEnableEquipment    		 Boolean true Turns the equipment system on or off (read at start, default only). Off: nothing is equipped and the equipment input is ignored.

    Equipment > HandIK¶

    Variable Type Default Description
    Left Hand Bone
    LeftHandBone    		 Name hand_l Left hand bone of the character skeleton; the hand IK and ADS targets are expressed in its space. Default hand_l (UEFN, UE5 and MetaHuman skeletons).
    Right Hand Bone
    RightHandBone    		 Name hand_r Right hand bone of the character skeleton; the hand IK and ADS targets are expressed in its space. Default hand_r (UEFN, UE5 and MetaHuman skeletons).

    Equipment > Selection¶

    Variable Type Default Description
    Selected Equipment
    SelectedEquipment    		 Enum_Equipment Unequip Equipment slot currently selected. Replicated with RepNotify; changing it respawns the equipment actor and relinks the overlay poses. (replicated (RepNotify))

    Equipment > UI¶

    Variable Type Default Description
    Equipment Menu Widget Class
    EquipmentMenuWidgetClass    		 UserWidget class W_Switcher_Equipment Widget shown while the equipment menu key is held. Default W_Switcher_Equipment. A replacement only needs to display the component's HighlightedEquipment (read it every tick); scrolling and selecting are handled by this component.
    Menu Time Dilation
    MenuTimeDilation    		 Float 0.35 World time dilation while the menu is open (1 = no slow motion). Global: on a listen server the host's menu slows every player. Default 0.35.
    Runtime state (16 variables)
    Variable Type Default Description
    IK Hand Left
    IK_HandLeft    		 Transform Third person: equipment 'HandIK' socket in hand_r bone space. Target transform for the left hand IK.
    IK Hand Left FP
    IK_HandLeft_FP    		 Transform First-person version of IK_HandLeft, measured on the first-person equipment mesh and attach mesh.
    IK Hand Right
    IK_HandRight    		 Transform Third person: equipment 'HandIK' socket in hand_l bone space. Target transform for the right hand IK.
    IK Hand Right FP
    IK_HandRight_FP    		 Transform First-person version of IK_HandRight, measured on the first-person equipment mesh and attach mesh.
    IK ADS
    IK_ADS    		 Transform Third person: equipment 'ADS' socket in the weapon hand's bone space (hand_l if left-handed, else hand_r). Used to align sights.
    IK ADS FP
    IK_ADS_FP    		 Transform First-person version of IK_ADS, measured on the first-person equipment mesh and attach mesh.
    Parent Mesh TP
    ParentMesh_TP    		 SkeletalMeshComponent ref Third-person character mesh. Receives the third-person overlay pose layers.
    Parent Mesh FP
    ParentMesh_FP    		 SkeletalMeshComponent ref First-person lead mesh (arms/body). Receives the first-person overlay pose layers.
    Attach Mesh TP
    AttachMesh_TP    		 SkeletalMeshComponent ref Third-person mesh that equipment attaches to, using the equipment's TP socket and offset.
    Attach Mesh FP
    AttachMesh_FP    		 SkeletalMeshComponent ref First-person mesh that the first-person equipment copies attach to, using the equipment's FP socket and offset.
    Overlay Control Provider
    OverlayControlProvider    		 ActorComponent ref The owner's component implementing BPI_OverlaySystem (cached), or None.
    Equipment Data
    EquipmentData    		 PDA_Equipment ref Data row chosen by CHT_Equipment for the selected slot: actor class, overlay poses, attach sockets, offsets, left-handed flag.
    Spawned Actor
    SpawnedActor    		 Actor ref Equipment actor currently spawned on the parent pawn. Destroyed and replaced by UpdateEquipment.
    Equipment Switcher
    EquipmentSwitcher    		 UserWidget ref Equipment switcher widget instance (W_Switcher_Equipment) shown while the selection menu is open.
    Menu Open
    bMenuOpen    		 Boolean false True while the equipment selection menu is open.
    Highlighted Equipment
    HighlightedEquipment    		 Enum_Equipment Unequip Item highlighted in the open equipment menu: starts on SelectedEquipment, moved by scrolling (CycleHighlightedEquipment), equipped on release (ConfirmEquipmentMenu). The menu widget displays it.

    Functions¶

    Function Inputs Outputs Description
    GetFirstPersonHandTargets   ADSTarget (Transform), HandLeftTarget (Transform), HandRightTarget (Transform), bIsLeftHanded (Boolean), bHasFirstPersonOverlay (Boolean)  
    GetFirstPersonItemSettings   bHasItem (Boolean), ADSEnterSpeed (Float), ADSExitSpeed (Float), ADSHandOffset (Vector), MotionProfile (PDA_FirstPersonMotion ref)  
    GetHeldItemHands   bLeftHand (Boolean), bRightHand (Boolean)  
    GetEquipmentMesh (pure) bFirstPerson (Boolean) Mesh (PrimitiveComponent ref) Mesh of the spawned item for hand IK sockets: in first person its first first-person copy (ItemFirstPersonCopies), else its first mesh (ItemThirdPersonMeshes), else its first MeshComponent. No rendering tags needed.
    GetHandIK SocketName (Name), TargetBoneName (Name), bIsFirstPerson (Boolean) Result (Transform), Result_Location (Vector), Result_Rotation (Rotator), Result_Scale (Vector) Returns an equipment socket's transform in the bone space of TargetBoneName on the TP or FP attach mesh. Returns identity if the equipment or meshes are invalid.
    UpdateHandIK     Recomputes all six hand IK transforms (left, right, ADS; TP and FP) from the spawned equipment: the equipment data's HandIKSocket / ADSSocket in the space of LeftHandBone / RightHandBone. Called after spawning and every tick by the bow.
    GetOverlayControlProvider (pure)   ReturnValue (ActorComponent ref) The cached BPI_OverlaySystem component of the owner, or None.
    ApplyEquipmentSwitch     When bEnableEquipment is off: selects Unequip before the first update.
    InitializeSystem ParentPawn (Pawn ref), ParentMesh_TP (SkeletalMeshComponent ref), ParentMesh_FP (SkeletalMeshComponent ref), AttachMesh_TP (SkeletalMeshComponent ref), AttachMesh_FP (SkeletalMeshComponent ref)   Stores the pawn and mesh references, spawns the initial equipment and binds cleanup to the pawn's OnDestroyed. Called by the owning character.
    DestroySpawnedActors DestroyedActor (Actor ref)   Bound to the parent pawn's OnDestroyed. Destroys the spawned equipment actor so it does not outlive its owner.
    LinkFirstPersonOverlayPose     Links the slot's OverlayPose_FP onto the first-person lead mesh (ParentMesh_FP) and the first-person attach mesh, skipping a mesh that does not exist: a third-person-only pawn (AllowedPerspectives without FirstPerson) builds no first-person meshes. Called by UpdateEquipment.
    LinkThirdPersonOverlayPose     Links the third-person overlay pose for the current slot. An item that spawns an actor links its own pose (EquipmentData OverlayPose_TP). With nothing in hand (Unequip) the pawn's AC_OverlaySystem applies its selected stance (Default, Injured, HandsTied...), so a stance chosen on the pawn survives spawn and unequipping; without an overlay system the slot's pose is linked as before. Called by UpdateEquipment.
    PrepareItemMeshes Item (Actor ref)   Fills ItemThirdPersonMeshes with the item's mesh components and, when the pawn has a first-person system and the item's bCreateFirstPersonCopy is on, ItemFirstPersonCopies with its copies.
    ReleaseItemMeshes Item (Actor ref)   Clears the item lists and asks the pawn's first-person system to remove the item's copies. Call it before destroying the item.
    UpdateEquipment     Destroys the old equipment, evaluates CHT_Equipment for the selected slot, links the overlay anim layers, spawns the actor, attaches its TP and FP parts and refreshes hand IK.
    CloseEquipmentMenu     Closes the equipment menu without selecting anything: removes the switcher widget and restores global time dilation to 1. Called from EndPlay, so a pawn destroyed with the menu open does not leave the game slowed down.
    ConfirmEquipmentMenu     Equips HighlightedEquipment (SelectNewEquipment) and closes the menu.
    CycleHighlightedEquipment bNext (Boolean)   Moves HighlightedEquipment to the next (bNext) or previous Enum_Equipment value, wrapping around.
    OpenEquipmentMenu     Opens the equipment menu for the owning player: MenuTimeDilation, highlight on the current item, EquipmentMenuWidgetClass added to the viewport.

    Events¶

    • UpdateSelectedEquipment: Server RPC, reliable.

    BPI_EquipmentSystem¶

    /GASPALS/Systems/EquipmentSystem/BPI_EquipmentSystem · parent Interface

    What other systems ask the equipment system.

    Functions¶

    Function Inputs Outputs Description
    GetFirstPersonHandTargets   ADSTarget (Transform), HandLeftTarget (Transform), HandRightTarget (Transform), bIsLeftHanded (Boolean), bHasFirstPersonOverlay (Boolean) First-person hand IK and ADS targets of the current item (IK_*_FP), its handedness and whether it has a first-person overlay pose.
    GetFirstPersonItemSettings   bHasItem (Boolean), ADSEnterSpeed (Float), ADSExitSpeed (Float), ADSHandOffset (Vector), MotionProfile (PDA_FirstPersonMotion ref) The current item's first-person settings (ADS speeds and hand offset, motion profile); bHasItem false when there is none.
    GetHeldItemHands   bLeftHand (Boolean), bRightHand (Boolean) Which hands hold the current item (both false when unequipped or disabled).

    PDA_Equipment¶

    /GASPALS/Systems/EquipmentSystem/Data/PDA_Equipment · parent PrimaryDataAsset

    Settings¶

    Equipment > ADS¶

    Variable Type Default Description
    ADSEnter Speed
    ADSEnterSpeed    		 Float 15 First person: how fast the weapon blends into aim down sights (CR_FirstPerson_ADS ADS_Speed_Enter). Default 15.
    ADSExit Speed
    ADSExitSpeed    		 Float 5 First person: how fast it blends out of aim down sights (ADS_Speed_Exit). Default 5.
    ADSHand Offset
    ADSHandOffset    		 Vector (0, 0, 0) First person: offset (cm, head space at the reference pose, same axes as the body's EyeOffset in its first-person setup) added to the ADS hand targets: moves the weapon toward or away from the eyes while aiming.

    Equipment > Attach¶

    Variable Type Default Description
    Spawned Actor
    SpawnedActor    		 Actor class  
    Is Left Handed
    bIsLeftHanded    		 Boolean false  
    Attach Socket TP
    AttachSocket_TP    		 Name  
    Attach Offset TP
    AttachOffset_TP    		 Transform  
    Attach Socket FP
    AttachSocket_FP    		 Name  
    Attach Offset FP
    AttachOffset_FP    		 Transform  

    Equipment > FirstPerson¶

    Variable Type Default Description
    First Person Motion Profile
    FirstPersonMotionProfile    		 PDA_FirstPersonMotion ref First-person motion profile while this item is equipped. Empty = the pawn's default profile (AC_FirstPersonSystem).
    Create First Person Copy
    bCreateFirstPersonCopy    		 Boolean true Make a first-person copy of this item's meshes (shown in first person, attached to the first-person hand). Off: the item is only seen in third person.

    Equipment > HandIK¶

    Variable Type Default Description
    Hand IKSocket
    HandIKSocket    		 Name HandIK Socket on the equipment mesh where the off hand grips it (hand IK target). Default HandIK. A mesh without this socket gives no usable off-hand IK.
    ADSSocket Name ADS Socket on the equipment mesh used as the sight for aiming down sights (first-person ADS and the aim hand target). Default ADS.

    BP_Equipment_Bow¶

    /GASPALS/Systems/EquipmentSystem/Actors/BP_Equipment_Bow · parent Actor

    The only item actor with logic: it eases Draw toward 1 while the owner aims and updates the hand IK every frame.

    Settings¶

    Variable Type Default Description
    Draw Float 0 Bow draw amount from 0 (relaxed) to 1 (fully drawn). Read by the bow animation.
