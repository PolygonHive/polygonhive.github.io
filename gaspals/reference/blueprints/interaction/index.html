    Interaction reference¶

    The takedown and shove component and its two movement adapters, on both pawns. Add AC_InteractionSystem_Mover to a Mover pawn or AC_InteractionSystem_CMC to a Character pawn: both inherit every setting of AC_InteractionSystem_Base.

    How to read these tables

    Settings are the values you tune: select the component in your pawn Blueprint (or open the asset) and look in the Details panel under the category shown. Runtime state is written by the system while it runs; read it, do not set it. Functions marked pure have no execution pins. The descriptions are the same as the Details panel tooltips. Default is the class default; where a sample pawn sets a different value on its component, the description says so ().

    AC_InteractionSystem_Base¶

    /GASPALS/Systems/InteractionSystem/AC_InteractionSystem_Base · parent ActorComponent

    Settings¶

    Interaction > Debug¶

    Variable Type Default Description
    Draw Interactable Debug
    bDrawInteractableDebug    		 Boolean true Draw a small sphere above each character the locally controlled player can interact with.

    Interaction > General¶

    Variable Type Default Description
    Enable Character Interactions
    bEnableCharacterInteractions    		 Boolean true Master switch: off, LMB / E start no takedown or shove from this character (it can still be the target of one).

    Interaction > Input¶

    Variable Type Default Description
    Interaction Input Buffer Time
    InteractionInputBufferTime    		 Float 0.3 Seconds a takedown or shove key press stays buffered when no character is in range; the press fires as soon as one becomes interactable (UpdateInputBuffer). 0 turns the buffer off. Default 0.3.

    Interaction > Networking¶

    Variable Type Default Description
    Server Max Interaction Distance
    ServerMaxInteractionDistance    		 Float 350 Server check on a client's request: every other participant must be within this distance in cm. Default 350.

    Interaction > Search¶

    Variable Type Default Description
    Interaction Search Radius
    InteractionSearchRadius    		 Float 200 Radius in cm of the search for characters to interact with (around the owner, every tick on the locally controlled owner). Default 200.
    Interaction Height Tolerance
    InteractionHeightTolerance    		 Float 50 Largest height difference in cm between the owner and a candidate. Default 50.
    Interaction Max Angle
    InteractionMaxAngle    		 Float 60 Largest angle in degrees between the owner's facing and the direction to a candidate. Default 60.
    Interaction Clearance Radius
    InteractionClearanceRadius    		 Float 20 Radius of the capsule swept from the owner to a candidate; anything else in the way (CharacterCapsule profile) drops the candidate. Default 20.
    Interaction Clearance Half Height
    InteractionClearanceHalfHeight    		 Float 60 Half height of that clearance capsule. Default 60.
    Search Interactions for AI
    bSearchInteractionsForAI    		 Boolean false Search for interaction candidates (overlap and clear-path sweeps every frame) on AI-controlled pawns too. Off by default: only player-controlled pawns start takedowns and shoves. AI can still be the target of an interaction.

    Interaction Request Valid
    bInteractionRequestValid    		 Boolean false Server, while validating a client request (ValidateInteractionRequest): true while the requester can start an interaction and every other participant passes ValidateParticipant.
    Body Contacts Suppressed
    bBodyContactsSuppressed    		 Boolean false The owner's mesh ignores PhysicsBody for the current interaction (SuppressBodyContacts); UpdateBodyContacts sets Block back.
    Body Contacts Suppress Time
    BodyContactsSuppressTime    		 Float 0 Game time of the last SuppressBodyContacts call (UpdateBodyContacts waits at least 0.3 s).
    Interaction Pending
    bInteractionPending    		 Boolean false True while a buffered key press waits for a character in range (TryCharacterInteraction sets it, UpdateInputBuffer fires or drops it). Locally controlled owner only.
    Pending Interaction Type
    PendingInteractionType    		 Name Interaction type of the buffered key press (row name of CHT_CharacterInteractionPSDs, e.g. Takedown, Shove), fired by UpdateInputBuffer.
    Pending Interaction Time
    PendingInteractionTime    		 Float 0 Game time of the buffered key press; UpdateInputBuffer drops it once InteractionInputBufferTime has passed.
    Request Has Instigator
    bRequestHasInstigator    		 Boolean false Server, while validating a client request (ValidateInteractionRequest): true once a participant is the requesting character itself (ValidateParticipant). A request without the requester among its participants is dropped.

    Functions¶

    Function Inputs Outputs Description
    DispatchInteraction InteractionType (Name), Results (Array of PoseSearchBlueprintResult)   Builds Participants from the query results. Server: multicasts them (every machine applies them). Client: applies them locally as a prediction and sends them to the server (Server_TryCharacterInteraction).
    TryCharacterInteraction InteractionType (Name)   Starts an interaction of InteractionType (row name of CHT_CharacterInteractionPSDs, e.g. Takedown, Shove) with the characters in InteractableActors. Called by the IA_Takedown / IA_Interact input events. With no candidate the press is buffered for InteractionInputBufferTime (UpdateInputBuffer).
    TryMultiCharacterInteraction InteractionType (Name), Other Actors (Array of Actor ref)   Runs the chooser and the motion match multi query for the owner and the other actors, then dispatches the results (DispatchInteraction).
    GetMeshForInteraction   Mesh (SkeletalMeshComponent ref) The owner's character mesh, callable on another character's component.
    Get_MMIAnimContexts (pure)   AnimContexts (Array of Object ref) Anim instances of every participant of the current interaction (BPI_SandboxCharacter_Pawn.Get_MMIAnimContexts forwards here).
    Get_MMIResult (pure)   Result (PoseSearchBlueprintResult) The current interaction result (BPI_SandboxCharacter_Pawn.Get_MMIResult forwards here).
    IsOwnerAiming (pure)   bIsAiming (Boolean) True while the owner wants to aim (BPI_SandboxCharacter_Pawn properties): LMB and E then belong to the weapon, not to takedowns and shoves.
    UpdateInputBuffer     Locally controlled owner, every tick after the search: a buffered key press fires TryCharacterInteraction once a character is in range, or is dropped after InteractionInputBufferTime.
    HandleMulticast     Every machine: applies the replicated participants without prediction; the adapters skip the montage the owning client already plays.
    HandleServerRequest     Server: a valid client request is applied and multicast to every machine; an invalid one is dropped.
    ValidateInteractionRequest   bValid (Boolean) Server check of a client request: the requester can start an interaction (CanStartInteraction), every other participant passes ValidateParticipant, and the requester is one of the participants (bRequestHasInstigator).
    ValidateParticipant Participant (S_InteractionParticipant)   Server check of one participant of a client request. The requester itself sets bRequestHasInstigator; any other participant needs an interaction component, an interactable state and a distance within ServerMaxInteractionDistance, else the request is invalid.
    AddParticipantContext Participant (S_InteractionParticipant)   Adds the participant's anim instance to LocalContexts.
    ApplyParticipantLinks Other (AC_InteractionSystem_Base ref)   Links the owner with another participant: the two capsules ignore each other when moving (cleared when the montage blends out), and, when both use the same adapter class, the owner's mesh ticks after the other's (a Mover mesh made to wait for a CMC mesh, which ticks later, stops showing its montage).
    ApplyParticipants bLocalPrediction (Boolean)   Applies Participants on this machine: suppresses the owner's body contacts (SuppressBodyContacts), collects every participant's anim instance into LocalContexts, then applies each participant (ApplyToParticipant). bLocalPrediction is true for the requesting client's prediction.
    ApplyToParticipant Participant (S_InteractionParticipant), bLocalPrediction (Boolean)   Sets the participant's interaction result and anim contexts, plays its montage (PlayInteraction) and links it with the owner (ApplyParticipantLinks).
    PlayInteraction bLocalPrediction (Boolean), Instigator (Pawn ref)   Plays the interaction montage for this machine's role. Base: on the mesh (PlayInteractionMontage); the adapters override it (Mover: root motion through the CharacterMover on the authority and the predicting owner).
    RestoreBodyContacts     Sets the mesh back to blocking PhysicsBody after SuppressBodyContacts.
    SetInteractionResult Result (PoseSearchBlueprintResult), AnimContexts (Array of Object ref)   Stores the interaction result and anim contexts read by the anim blueprint (Get_MMIResult / Get_MMIAnimContexts).
    SuppressBodyContacts     Instigator of an interaction: the mesh stops colliding with PhysicsBody (other characters' ragdolls) while its montage plays, so its animated bodies don't blow the victim's ragdoll apart when the victim ragdolls. Only when the mesh blocked PhysicsBody; RestoreBodyContacts sets Block back.
    UpdateBodyContacts     Every tick: restores the body contacts once no montage plays on the mesh (at least 0.3 s after the suppress, so the interaction montage has started). Works on every machine, whatever plays the montage.
    CheckForInteractableCharacters     Clears InteractableActors and, when the character can start an interaction, fills it with the pawns within InteractionSearchRadius that pass IsCandidate (debug sphere above each for a player with bDrawInteractableDebug).
    GetInteractionSpeed (pure)   Speed (Float) Owner speed in cm/s, a chooser input of the interaction query.
    HasClearPath Actor (Actor ref) bClear (Boolean) Sweeps a capsule (InteractionClearanceRadius / HalfHeight, CharacterCapsule profile) from the owner to the candidate, ignoring both: true when nothing is in the way.
    IsCandidate (pure) Actor (Actor ref) bIsCandidate (Boolean) A character this one could interact with: it has an interaction component in an interactable state and is within InteractionHeightTolerance and InteractionMaxAngle; only then the clearance sweep runs (HasClearPath).
    InitializeSystem ParentPawn (Pawn ref), ParentMesh (SkeletalMeshComponent ref), ParentCapsule (CapsuleComponent ref)   Stores the owner references: pawn, character mesh (its anim instance joins the interaction query and plays the montage) and capsule. Call from the owner's initialization. Adapters extend it to find their movement component.
    CanStartInteraction (pure)   bCanStart (Boolean) This character can start a takedown or shove: bEnableCharacterInteractions, an interactable movement state (IsInInteractableState) and no montage in the DefaultSlot.
    IsInInteractableState (pure)   bInteractable (Boolean) Movement state check, overridden by the adapters: Mover walking without anim root motion, CMC on the ground without a montage in the default slot. Base: false.
    IsInteractableNow   bInteractable (Boolean) Impure IsInInteractableState, callable on another character's component.
    UpdateInteraction     Every tick: restores the body contacts after an interaction (UpdateBodyContacts, every machine); on the locally controlled owner, when player-controlled or with Search Interactions for AI, it also refreshes InteractableActors (CheckForInteractableCharacters) and the buffered key press (UpdateInputBuffer).
    GetInteractionSystem (pure) Actor (Actor ref) InteractionSystem (AC_InteractionSystem_Base ref) The interaction component of an actor (any adapter), or none.
    GetParticipantActor (pure) Participant (S_InteractionParticipant) Actor (Actor ref) Actor of an interaction participant.
    GetParticipantResult (pure) Participant (S_InteractionParticipant) Result (PoseSearchBlueprintResult) Motion matching result of an interaction participant.
    GetResultRoleIndex (pure) Result (PoseSearchBlueprintResult) RoleIndex (Integer) Index of the result's role in its interaction asset (0 instigator, 1 target), for the participant order.
