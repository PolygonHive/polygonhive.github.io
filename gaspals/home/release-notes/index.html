    Release notes¶

    What changed in this release of GASPALS, and how to upgrade a project built on the previous version (1.0).

    1.2 (October 2026)¶

    GASPALS for Unreal Engine 5.8. This release turns the sample into a set of modular systems that work on both pawns: a new cover system, a rebuilt first-person system driven by data assets, one Mover pawn with ragdoll and takedowns, per-system switches and interfaces, and settings for everything that used to be a fixed value in a graph. If you built on 1.0, read Upgrading to 1.2 first.

    Highlights

    • Cover: soft and sticky cover, cover runs along the navmesh, corner turns, vaulting and aiming from cover, a cover marker, on both pawns and in multiplayer.
    • First person: one component on the pawn generates the first-person meshes of the pawn, the active character and the held item from a setup data asset per body. Three modes, aim down sights, procedural hand and item motion.
    • One Mover pawn with the ragdoll, physics control, takedowns, shoves and debug tools.
    • Modular systems: every system has an on/off switch and its own interface, and most components can be deleted from a pawn.
    • Configurable: perspectives, crosshair, camera offsets, trace channels, input contexts, hold or toggle, movement tuning, menus and widgets are settings.

    Pawns and movement¶

    Added

    • One Mover pawn. SandboxCharacter_Mover has the ragdoll movement mode, the Physics Control component and its profiles, takedowns and shoves, hit reactions and injury states, and the debug tools, in every game mode.
    • System switches: Enable Camera System, Enable First Person, Enable Cover, Enable Traversal, Enable Equipment, Enable Overlay, Enable Ragdoll (CMC) and Enable Debug Tools, read at start. See Turning systems on and off.
    • Deletable components: the equipment, overlay, first-person, CMC ragdoll and debug tools components can be removed from a pawn without breaking it.
    • System interfaces, one per system folder: BPI_CameraSystem, BPI_CameraSystemListener, BPI_FirstPersonSystem, BPI_CoverSystem, BPI_TraversalSystem, BPI_EquipmentSystem, BPI_OverlaySystem, BPI_RagdollSystem and BPI_RagdollSystemListener. The pawn interface BPI_SandboxCharacter_Pawn gains Get_AimRay (aim ray, trace channel and distance) and TeleportCharacter.
    • Input Mapping Contexts on both pawns (context and priority); an empty map shows a warning.
    • Console variable check: at play start the local player sees one orange message listing the GASPALS DDCvar.* console variables the project does not declare (BPFL_GASPALS.CheckConsoleVariables). A missing DDCvar.VisualOverride or DDCvar.PawnClass now means no override and the game mode's default pawn, instead of the first list entry.
    • Hold or toggle per action on both pawns: Toggle Crouch / Walk / Sprint / Aim / Strafe (defaults unchanged).
    • CMC pawn: auto-strafe and target lock with the same settings as the Mover pawn (the auto-strafe state replicates), and movement tuning that used to be fixed values: Gait Max Acceleration, Gait Ground Friction (with sprint speed ranges), Braking Deceleration, Stopping Braking Friction and Falling Rotation Rate.
    • Sprint Max Angle From Facing on both pawns.
    • Mover modes: Slide Cooldown (stops slide spam), Slide Enter Speed / Slide Exit Speed on the Slide mode; Just Landed Deceleration / Duration on the Walking mode; Falling Rotation Rate on the Falling mode; a Cover movement mode and transition.

    Changed

    • GM_Sandbox_Ragdoll, RagdollLevel, DefaultLevel and the ragdoll notifies use SandboxCharacter_Mover.
    • In cover the gait is Walk unless crouched, and Sprint during a cover run. The Mover slide never starts in cover.
    • The CMC pre-tick runs after the controller, so cover and movement read this frame's input.

    Fixed

    • The Mover ragdoll mode reads the pawn's capsule size instead of fixed values.

    Input¶

    Added

    • IA_StickyCover and IA_CoverRun, both on Q by default. Map IA_CoverRun to its own key to split them.
    • X (IA_Ragdoll) ragdolls the Mover pawn, the same key as on the CMC pawn. While ragdolling, X again or Space (gamepad X or A) gets up, on both pawns.

    Changed

    • Ragdoll input is the same on both pawns, and the character only gets up once the body rests on a floor (a press in mid-air does nothing; press again after landing). Before, the Mover pawn got up only with Space (X ragdolled again), and the CMC pawn toggled with X even in mid-air while Space did nothing.

    • The DefaultLevel input board (W_InputWall, keyboard) and the Controls editor utility widget (keyboard and controller) list the current bindings: cover and cover run, interact, ragdoll and get-up, camera perspective, style and shoulder, the menus, the Mover-only takedown, demo shot, spawn / rotate and debug flying, teleport, next pawn and next character.

    • IA_Crouch, IA_Walk and IA_Strafe fire on press and on release (for hold mode).

    • Mover debug flying moved from the gamepad left stick click to Z (keyboard only); the left stick click only toggles strafe.
    • On the Mover pawn, Left Button is a takedown and E a shove; with aim held they are the demo shot and spawn or rotate.

    Removed

    • IA_Traverse (traversal runs from IA_Jump), IA_TriggerRagdoll (formerly R; unmapped and unused), the unused IMC_GASPALS_* contexts, and the ... (2) duplicate input assets and mobile HUD textures.

    Camera¶

    Added

    • Allowed Perspectives: first person only, third person only, or any mix; the perspective input cycles them, and the start and ragdoll views fall back when not allowed (with a warning, except for a ragdoll view left at its TopDown default). Third Person Camera Bone.
    • Show Crosshair, Crosshair Widget Class, Aim Trace Channel and Aim Trace Distance.
    • Camera Offset Rigs per pawn (crouch, right shoulder, low cover, cover edges, first-person scale, in air, sliding, traversing, ragdoll); clearing an entry turns that offset off. Pass Movement Mode To Camera feeds the movement-mode rigs.
    • RegisterCameraListener: components implementing BPI_CameraSystemListener hear every perspective change.

    Changed

    • The crosshair is a dot at the aim point for the local player, in every perspective; the widget only draws it.
    • The ragdoll camera works on both pawns. Only the owning player's copy switches; the perspective replicates.
    • The first-person field of view comes from CameraRig_FP_Base; the first-person scale applies only in Split mode (CameraRig_FP_Scale). The first-person camera follows the body setup's Camera Bone.
    • CameraShake_Basic moved to /GASPALS/Systems/CameraSystem.

    Fixed

    • Restricting Allowed Perspectives (third person only, for example) no longer warns that Camera Perspective During Ragdoll is not available while that setting is at its TopDown default; the ragdoll keeps the current view. The camera's first-person warnings name AC_FirstPersonSystem.

    Removed

    • Enable First Person Rendering, Enable First Person Field Of View, First Person Field Of View, Enable First Person Scale and First Person Scale (see Changed).
    • The old camera copy /GASPALS/Blueprints/Cameras and CameraRig_FP_Offset_Crouch (the first-person camera follows the head).

    Cover¶

    Added

    • A new cover system: AC_CoverSystem_Base with the AC_CoverSystem_Mover and AC_CoverSystem_CMC adapters (the sample pawns keep the component name AC_CoverSystem). See Cover.
    • Soft (auto) and sticky cover, low cover with Auto Crouch Low Cover, High Cover Height measured from the feet, stops at edges, gentle bends and chained corner turns.
    • Cover run along the navmesh: hold the cover run button; a tap prefers sticky cover; a started run finishes after the button is released.
    • Vault from cover, and aim from cover (Enable Cover Aim) with the least exposed pose that can hit.
    • Pelvis lowering behind low walls, once the character has reached the wall (Cover Lower Settle Tolerance).
    • Cover camera offsets and shoulder switch (Enable Cover Camera Offsets, Enable Cover Shoulder Switch), and first-person behaviors (First Person Sticky Cover, First Person Auto Cover).
    • The cover marker (Show Cover Marker, Cover Marker Widget Class, Draw Size, Wall Offset) and Cover Trace Channel.
    • Switches and tuning: Enable Auto Cover, Enable Sticky Cover, Enable Cover Run, Engage Rule, Move Into Cover, wall distances per stance and cover type, facing, side input threshold, probes, re-entry cooldowns, cover run timing, and Enable Debug (draws the cover traces).
    • Multiplayer on both pawns. Cover is on by default.

    Removed

    • The previous AC_CoverSystem class and the pawn-level cover variables (see Upgrading to 1.2).

    Traversal¶

    Added

    • Traversable Trace Channel and Room Check Trace Channel.
    • Traversal > Check settings per pawn: trace radius, half heights, speed and reach ranges, air reach.
    • First Person Traversal Turn Speed / Threshold, and traversal from cover (the cover vault).

    Changed

    • AC_TraversalLogic replicates on the Mover pawn.

    Fixed

    • Traversal no longer starts twice for a pawn the server controls locally (listen-server host, standalone, server AI).
    • Mover pawn: the 2 m mantle no longer ends low inside the ledge.

    Equipment¶

    Added

    • Revolver: a one-handed item (DA_Equipment_Revolver, BP_Equipment_Revolver, the M9 mesh) using the Pistol1H overlay in third person and the new ABP_OverlayFirstPerson_Pistol1H in first person (high-ready hold, one-handed aim down sights).
    • Left Hand Bone / Right Hand Bone, Equipment Menu Widget Class and Menu Time Dilation on the equipment component.
    • Per item (PDA_Equipment): Hand IK Socket, ADS Socket, ADS Enter Speed / ADS Exit Speed, ADS Hand Offset, First Person Motion Profile and Create First Person Copy.

    Changed

    • Item actors have a single mesh; the pawn's first-person system makes their first-person copies (owner only, no collision).
    • The equipment component owns the menu highlight; the menu widget only displays it.
    • Menu order: Unequip, Rifle, Pistol, Revolver, Bow, Torch, Binoculars, Box, Barrel. The Revolver moved after the Pistol in Enum_Equipment, which the menu follows.

    Fixed

    • The menu opens for the pawn's own player controller (not player 0). A client sends its selection once instead of twice. Unequipping resets the hand IK targets. Destroying the pawn with the menu open removes the menu and restores the world speed.

    Removed

    • The hand-made _FP item meshes and first-person tags, ABP_Equipment_HandIK, and the switcher widgets' CycleState. DestorySpawnedActors is renamed DestroySpawnedActors.

    Overlays and animation¶

    Added

    • Overlay Pose Layers and Overlay Body Layers maps: a new stance or body style is a map row (a value with no row prints a warning). Overlay Pose / Body Menu Widget Class and Menu Time Dilation on the overlay component.
    • Ready Hold Time Idle / Moving and Aim Min Time per overlay.
    • Aim Smoothing Time Local / Remote on the character Anim Blueprints and Aim Sweep Interp Speed Local / Remote on the overlays.

    Changed

    • The legs layer is enabled: overlay stances show in the legs (layering_legs, layering_pelvis).
    • Overlay changes are instant.
    • The local player's weapon aim follows the view in the same frame (Local values 0, the Mover uses the live control rotation): no lag and no stepping when turning.

    Fixed

    • A stance set on the pawn shows at spawn and comes back after unequipping.
    • Injured and HandsTied are real overlays.
    • Mover foot placement measures the leg bone lengths, so knees no longer bend or twist under overlay leg poses.

    First person¶

    Added

    • AC_FirstPersonSystem, on the pawn only. It generates the first-person meshes of the pawn, of the active retargeted character and of the held item. See First person.
    • Setup data assets (PDA_FirstPersonSetup): Full Meshes, Arms Meshes, Body Meshes, Retargeter, Eye Offset, Camera Bone, Head Bone, and the advanced Pipeline Anim Class, Retarget Host Anim Class and Mesh Suffix. One per body: DA_FirstPersonSetup_UEFN (both pawns), _Manny, _Quinn, _Kellan.
    • First Person Mode: FirstPersonOverlay (default), FirstPersonOverlaySplit and TrueFirstPerson (also the automatic fallback for a body without a retargeter), set on the pawn for every body.
    • Settings: arm pitch limits, First Person Camera Follow Lean, First Person Full Body View, First Person Camera Vertical Smoothing, First Person Max Root Yaw Lag.
    • First-person motion: procedural hand and item motion (look and move sway, bob, breathing, jump and landing kicks) that fades while aiming; the camera never moves. Profiles (PDA_FirstPersonMotion: Unarmed, Pistol, Rifle, Heavy), per item or per pawn, a global First Person Motion Intensity and a disable_fp_motion montage curve. See Tune first-person motion.
    • MetaHuman clothing support, the template Anim Blueprint ABP_FirstPerson_Host for other skeletons, the editor tool EUB_SplitFirstPersonMesh, and on-screen setup warnings.
    • Generated meshes are AC_FirstPersonSkeletalMesh / AC_FirstPersonStaticMesh components, which remove themselves cleanly when the body or the item changes.

    Changed

    • No component tags: the third-person mesh and everything attached under it is the third-person body.

    Removed

    • AC_FirstPersonRendering (replaced by AC_FirstPersonSystem), first-person components on characters and items, ABP_FirstPerson_UE5, the unused ABP_FirstPerson_CopyPose and the CR_FirstPerson_StableBones rigs.

    Characters¶

    Added

    • Default Visual Override and Follow Global Visual Override per pawn (fixed characters, game modes other than GM_Sandbox).
    • First Person Setup on retargeted characters, BPI_VisualOverride (GetVisualBodyMesh), and first-person arms and no-arms meshes for Manny, Quinn and Kellan.

    Changed

    • Switching character hides only the pawn's third-person body. The body mesh no longer has to be the first child of the root.
    • The CMC pawn's manager component is named AC_VisualOverrideManager, like on the Mover pawn. Kellan's Blueprint is renamed BP_RetargetedCharacter_Kellan.

    Fixed

    • Loading Kellan no longer reports load errors or LOD warnings.

    Removed

    • The unused ABP_CopyPose_UEFN (a copy-pose Anim Blueprint for characters on the UEFN skeleton; see Characters to make one).

    Ragdoll and interactions¶

    Added

    • Ragdoll settle (Mover): Ragdoll Settle Speed, Delay and Blend Time; a ragdoll lying still no longer shakes its hands.
    • Obstacle course: Ragdoll On Obstacle Hit, Ragdoll Obstacle Object Types, Ragdoll Obstacle Trace Radius.
    • CMC ragdoll entry: Inherited Velocity Scale (a running character keeps its momentum), Left Leg Bones / Right Leg Bones (the legs collide with each other).
    • BPI_RagdollSystem (RequestRagdoll, ApplyRagdollImpulse, IsRagdollActive, RequestGetUp) on the CMC component and the Mover pawn. RequestGetUp ends the ragdoll and plays the get-up only while ragdolling on a floor; both pawns' ragdoll and jump inputs call it (the CMC pawn through Ragdoll_RequestGetUp).
    • Bench interaction settings: trace start and end distance, half extent and object types.

    Changed

    • DDCVar.CharacterPhysics.DefaultProfile is 0: outside ragdoll the Mover body is kinematic, so hands no longer catch on walls. Set it to 1 for the physical animation profile.
    • AC_RagdollSystem is for the CMC pawn only (the Mover pawn ragdolls through its movement mode).
    • Same ragdoll and get-up keys on both pawns, and get-up only on a floor (see Input).

    Fixed

    • CMC: leaving ragdoll restores the capsule and mesh collision the pawn had before and puts the mesh back on the capsule.
    • Mover: ragdoll entry, exit and takedowns restore the capsule's own collision profile.
    • Mover, packaged game: the ragdoll physics profiles no longer stop applying about a minute after start. The PhysicsControl component holds its Physics Control Asset through a soft reference only, so the asset was garbage-collected; the pawn now keeps the loaded asset in LoadedPhysicsControlAsset from BeginPlay.

    Debug tools¶

    Added

    • AC_DebugTools on the Mover pawn (/GASPALS/Systems/DebugTools): demo shot (aim + Left Button), spawn or rotate (aim + E), teleport (J) and debug flying (Z), with Enable Debug Tools, Shot Trace Distance, Shot Impulse, Spawn Trace Distance, Max Spawned Characters and Teleport Max Distance. See Debug tools.

    Removed

    • The former ragdoll pawn's demo functions and its separate crosshair.

    Multiplayer¶

    Fixed

    • The Mover pawn's camera and traversal components and the CMC pawn's visual override manager replicate. The camera perspective replicates both ways, and a client's character change reaches every machine.
    • Possession setup, input state and character switching (M) use reliable RPCs.
    • CMC: a ragdoll impulse (ApplyRagdollImpulse on the server) pushes the body on every machine, not only on the server.
    • CMC: other machines no longer log an error every frame in the top-down and side-scroller views.
    • Cover lowering looks the same on every machine.

    Project¶

    Added

    • GASPALS.uplugin declares the engine plugins the content uses, with the docs and support links.
    • A Cover trace channel (default Block; every engine profile answers it like Visibility).
    • Placed CMC and Mover characters and a navigation volume in DefaultLevel.
    • A Credits and license page, and a plugin README.md with the requirements, install steps and the documentation link.

    Changed

    • The GASPALS collision channels moved to the last slots (ECC_GameTraceChannel15 to 18) so they don't clash with a project's own channels.
    • The project file is GASPALS.uproject. Packaging settings point at /GASPALS paths, and the Win64 package builds.
    • Every system Blueprint has categories (<System>|<Feature>), descriptions and commented graphs.

    Fixed

    • No plugin asset references missing /Game content.

    Removed

    • The LookAtPOI example's About videos, which were never shipped, and their media assets; the About pages keep their text.

    Upgrading to 1.2¶

    From GASPALS 1.0:

    1. Collision: copy the new collision block from Installation (the channel slots moved and Cover was added). If your project has its own channels, pick these again by name: Traversable Trace Channel (AC_TraversalLogic), Cover Trace Channel (AC_CoverSystem) and Ragdoll Obstacle Object Types (Mover pawn). Components with Custom collision need a Cover response (Ignore when they ignore Visibility).
    2. Config: copy the console variables (DDCVar.CharacterPhysics.DefaultProfile is now 0), bAllowClientSideNavigation=True, the GameFeatureData asset scan rule, and the /GASPALS maps-to-cook and touch interface paths.
    3. SandboxCharacter_Mover_Ragdoll is removed: point child Blueprints, casts, placed actors and game modes at SandboxCharacter_Mover. Its demo functions are now AC_DebugTools; its ragdoll key is X.
    4. Cover: the previous AC_CoverSystem class is gone. Use AC_CoverSystem_Mover or AC_CoverSystem_CMC; the cover settings and Enable Cover live on the component. Custom pawns need the cover hooks and Get_AimRay, see Add the systems to your own pawn.
    5. First person: AC_FirstPersonRendering became AC_FirstPersonSystem, on the pawn only (set Default Setup). For each character, create a PDA_FirstPersonSetup with its first-person meshes, retargeter, bones and eye offset, and set it as First Person Setup. Remove first-person components, rendering tags and hand-made _FP item meshes from characters and items. Set the first-person mode and settings on the pawn only. Replace ABP_FirstPerson_UE5 and the StableBones rigs with a Retargeter in the setup (the host Anim Blueprint handles other skeletons).
    6. Camera: the first-person field of view and scale settings and Enable First Person Rendering are gone. Use Allowed Perspectives, CameraRig_FP_Base for the field of view and Split mode for the scale.
    7. Renames: BP_RetargetedCharacter_Kellan (was BP_RetargeterCharacter_Kellan), the CMC pawn's AC_VisualOverrideManager (was BP_VisualOverrideManager), DestroySpawnedActors (was DestorySpawnedActors), CameraShake_Basic in Systems/CameraSystem.
    8. Ragdoll: AC_RagdollSystem.InitializeSystem no longer takes IsMoverCharacter; remove the component from Mover-based pawns. BPI_RagdollSystem gained RequestGetUp: implement it on your own implementers to support the get-up keys (unimplemented, it returns false). If you copied the Mover pawn's Physics Control setup, keep a hard reference to the loaded Physics Control Asset, as LoadedPhysicsControlAsset does.
    9. Menus: the switcher widgets' CycleState is gone. Custom menus read the highlighted entry from the equipment or overlay component and are set through the ... Menu Widget Class settings.
    10. Input: map IA_StickyCover and IA_CoverRun in your own contexts; IA_Traverse, IA_TriggerRagdoll and the IMC_GASPALS_* contexts are deleted; IA_Crouch, IA_Walk and IA_Strafe also fire on release, so check your own handlers.
    11. Removed Anim Blueprints: ABP_CopyPose_UEFN and ABP_FirstPerson_CopyPose are deleted (they were unused); replace any reference to them in your own content.
    12. Equipment enum: the new Revolver sits after the Pistol in Enum_Equipment, so Bow, Torch, Binoculars, Box and Barrel have values one higher than in 1.0. Pins, data assets and chooser cells resolve by name; re-check anything that stores the equipment as a raw byte number.
    13. Feel: the overlay legs layer, instant overlay changes, unsmoothed local aim and the kinematic Mover body change how the sample feels; the settings above bring the old behavior back where you need it.
